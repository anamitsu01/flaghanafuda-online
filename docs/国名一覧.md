# 国名・色・地域の一覧

自動生成(`npm run flags`)。国名は `lib/flagList.ts`、色の手直しは `scripts/buildFlags.ts` の OVERRIDES で行う。

- 色は国旗の面積の2%以上を占めるものを数える(オレンジ・金は黄、えんじは赤、水色・紺は青に寄せる)。
- 文字数は「・」と( )の中を除いて数える。

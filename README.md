# 国旗花札 (Kokki Online)

世界の国旗を2枚ずつ集めて、色・地域・国名の役をそろえるカードゲーム(試作版、2〜6人)。
Next.js (App Router) + Socket.io によるリアルタイム対戦。陣取りゲーム・ザクロの継承と同じ構成です。

## ローカル開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。カスタムサーバー(`server.ts`)が
Next.jsとSocket.ioを同一プロセス・同一ポートで提供します(`next dev`単体では動きません)。

### 1人でテストする

トップ画面の部屋コード欄に **`ZZZZZ`** を入れて参加すると、ボット3体が入ったテスト部屋が作られます(`lib/bot.ts`)。

ルール処理をボット同士の対戦で検証するには:

```bash
npx tsx scripts/simulate.ts 300
```

## ルール(Ver.0.9 + 確定事項)

- 公開6枚と山札から、毎ターン合計2枚取る。公開の補充は手番の終わり。
- 公開の国旗は絵柄と色だけが見える。選んで確認に「はい」と答えると国名・地域・文字数が分かり、選び直せない。
- 山札から引いた国旗と保留カードは本人にだけ見える(役に置いた時点で全員に見える)。
- 公開から取った国旗はその場で役を決める。山札から引いた国旗は、すぐ置くか保留(上限3枚)。
- 保留カードを置けるのは、手番の最初(国旗を取る前)だけ。枚数は自由。
- 色役・地域役・模様役は、保留カードも含めて1ターンに各役1枚まで。国名役は無制限。
- 色役(赤・白・青・緑・黄・黒)/ 地域役(アジア・ヨーロッパ・アフリカ・アメリカ大陸・オセアニアの5地域): 5枚で完成、1点。完成後は追加も作り直しも不可。
- 模様役(星・月): 星のある国旗、月のある国旗をそれぞれ5枚で完成。星役は1点、月役は対象が少ないので3点。最多ボーナスはない。対象は `lib/flagSymbols.ts`。
- 完成した色役・地域役・模様役の国旗5枚は捨て札になり、山札がなくなったら捨て札を混ぜ直して山札にする(国名役の国旗は残る)。
- 国名役: 国名の合計20文字以上で完成、1点。完成後も置き続けられる。「・」と( )の中は数えない(例: ドミニカ(共和国)は4文字)。
- 最多ボーナス(各+2点): 色役最多(3役以上)、地域役最多(3役以上)、最長国名(完成済み)。
  先に条件を満たした人が持ち、ほかの人が記録を上回ったときだけ移る。
- 勝利: ラウンドの終わりに勝利点(既定10点)以上の人がいれば、その中の最高点が勝ち(同点は同着1位)。
  いなければ続行。山札・捨て札・公開がすべて尽きたら、そのラウンドの終わりに最高点の人が勝ち。

## 国旗データ

- `lib/flagList.ts`: 収録する国・地域と、ゲームで使う国名の正本(地域別)。
- `lib/flagColors.ts`: 各国旗の色(自動生成)。
- `lib/flagSymbols.ts`: 星・月のある国旗(手書き)。
- `docs/国名一覧.md`: 国名・文字数・色の一覧表(自動生成)。

国旗の画像は [flag-icons](https://github.com/lipis/flag-icons)(MIT)。国旗を追加・変更したら:

```bash
npx tsx scripts/analyzeFlags.ts   # 画像を public/flags にコピーし、色の面積を集計
npm run flags                     # 色データと一覧表を作り直す
```

色は面積2%以上のものを数えます(オレンジ・金→黄、えんじ→赤、水色・紺→青)。
自動判定を直したいときは `scripts/buildFlags.ts` の `OVERRIDES` に書きます。
